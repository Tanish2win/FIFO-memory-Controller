## Design Scope

The project focuses on the design and implementation of a synchronous FIFO memory controller with a defined data width and storage depth.

The design will be developed and evaluated through:

1. Architectural definition
2. RTL implementation
3. Functional verification
4. Logic synthesis
5. Floorplanning
6. Placement and optimization
7. Clock-tree synthesis
8. Routing
9. Physical verification
10. GDSII generation

## Documentation Policy

All documents will reflect the actual implementation status.

Planned features, completed features, simulation results, synthesis metrics, and physical-design results will be clearly distinguished. Results will only be reported after they have been obtained and verified.
